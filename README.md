# ☕ Coffee Delivery

Aplicação web para gerenciamento e pedido de cafés desenvolvida com React, Vite e Styled Components.

## 🚀 Tecnologias

- **React** com **Vite**
- **Styled Components** (Themeing e Global Styles)
- **React Router** (Navegação com layouts)
- **ContextAPI** (Gerenciamento de estado do carrinho)
- **LocalStorage** (Persistência dos dados)

## 💻 Como executar o projeto

```bash
# Instalar as dependências
npm install

# Executar a aplicação
npm run dev
